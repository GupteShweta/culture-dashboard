
# Culture Dashboard (React + Node + D3)

Features
- Interactive D3 cultural dimension chart
- Dataset of 120 countries
- Node.js API
- AI clustering model (KMeans)
- Dashboard and survey mockups

Folders
frontend/  React UI
backend/   Node Express API
data/      country dataset
ai/        clustering model
mockups/   dashboard UI wireframes

Run Backend
npm install express
node server.js

Frontend
Use Vite or React environment to run frontend.

Dataset fields
PDI - Power Distance
IDV - Individualism
MAS - Masculinity
UAI - Uncertainty Avoidance
LTO - Long Term Orientation
IVR - Indulgence
